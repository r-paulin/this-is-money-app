Cloudflare Pages (Git) — dependency install

Pages v3 often runs "bun install" before your build command, even when package-lock.json exists. Bun does not install this repo’s vendored @bolteu/* tarballs the same way npm does.

Required in the Cloudflare dashboard for this project:

1) Settings > Environment variables (Production and Preview as needed)
   Name:  SKIP_DEPENDENCY_INSTALL
   Value: 1

2) Settings > Builds > Build configuration
   Framework preset: Vite (or None)
   Build command:  npm run pages:build
   Build output:   dist
   Root directory: / (repo root)

3) Connect Git
   Repository: r-paulin/this-is-money-app
   Production branch: main

After saving, redeploy. The log should skip the automatic bun install; npm ci runs inside pages:build.

Confirm the deployment commit matches Git (log includes CF_PAGES_COMMIT_SHA).

Direct upload (optional, after `wrangler login`):
  npm run build && npx wrangler pages deploy ./dist --project-name=this-is-money-app
